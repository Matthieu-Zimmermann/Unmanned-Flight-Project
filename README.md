🚁 Paris Drone Simulator (Unity + Cesium)

This project is a drone flight simulator developed in Unity 6. It allows you to pilot a drone with realistic physics within a photorealistic 3D environment of Paris, generated dynamically using Cesium for Unity (Google Maps 3D Tiles).

Features Real-World Environment: Real-time rendering of Paris via the Cesium ion API. 
Flight Physics: Movement based on Unity's physics engine (Rigidbody) for realistic weight and inertia.Intuitive Controls: Support for standard keyboard inputs (WASD and arrows).
Collisions: The drone interacts with 3D buildings (Mesh Colliders generated by Cesium).
